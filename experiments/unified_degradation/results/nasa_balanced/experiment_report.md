# NASA 真实加速老化数据统一退化实验结果

## 数据与划分

- **capacitor**：23 个独立运行/器件组，138 条固定长度前缀序列；训练/验证/测试组数为 14/3/6。
- **igbt**：7 个独立运行/器件组，42 条固定长度前缀序列；训练/验证/测试组数为 4/1/2。
- **mosfet**：41 个独立运行/器件组，246 条固定长度前缀序列；训练/验证/测试组数为 25/6/10。

所有窗口均按原始器件或运行文件分组划分，同一原始曲线不会同时进入训练集和测试集。每个前缀被重采样到相同长度，模型不能通过序列点数推断标签。

## 结果解释边界

本实验预测的是各公开试验记录中的相对退化阶段，不直接等同于真实现场剩余寿命或失效概率。通用性的证据来自跨器件联合训练、分器件测试、器件专用模型对照和模块消融，而不是把不同器件的物理参数强行解释为同一个量。
