# NASA 分组留一应力水平确认性实验

## 协议审计

- **capacitor**：支持 applied_voltage 留一水平；10V (7 groups), 12V (8 groups), 14V (8 groups)；排除 0 组。
- **igbt**：不支持。IGBT does not support a discrete group-level stress holdout: its measured temperature and supply-voltage columns vary substantially within each run, while the nearly constant current column is response-derived and has only one effective level.
- **mosfet**：支持 supply_voltage 留一水平；5.61V (32 groups), 8.97V (4 groups)；排除 5 组。

## 解释边界

- 所有前缀以原始运行/器件 group 为单位进入且只进入 train、validation、calibration、test 或 excluded 之一；测试集是完整未见应力水平。
- capacitor 检验外加电压迁移；MOSFET 仅检验供电电压迁移，不应表述为未见热应力泛化。
- IGBT 缓存没有重复、离散且组内稳定的外加应力水平，因此不生成 LOSO 结果。
- MOSFET 两个方向的样本极不平衡，尤其低电压留出时只剩少量高电压训练组，必须逐方向报告，不能仅报告折间均值。
- PICP/MPIW 使用独立 calibration groups，并以每个 group 的最大前缀残差为 conformal score；由于测试应力发生分布迁移，90% 仅是目标水平，不构成有限样本覆盖保证。
- 预测目标仍是公开记录内的相对观测阶段；duration-only 是标签捷径诊断，不是可部署的健康估计方法。
