## 重跑研究实验

GPU 根因训练原环境为 Windows、Conda Python 3.9.18、PyTorch 2.5.1+cu121、RTX 4060，驱动及版本实录见 `meter_cause_v6_gpu_20261116/environment.json`。在可联网且已配置相容 NVIDIA 驱动和 Conda 的机器上，从交接包根目录执行：

```powershell
conda create -n meter-remf-train python=3.9.18 pip -y
conda activate meter-remf-train
python -m pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu121
python -m pip install -r research/meter_cause_v6_gpu_20261116/requirements-scientific.txt
python -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
python research/retrain_root.py
```

根因重训会在 `runs/root_时间/` 建独立实验目录，设置随包数据路径，依次执行原训练和评价程序。输出含每种子的检查点、验证选择、校准参数与逐台候选。原始协议中的磁盘路径保存在历史实验快照；请走上面的重训入口。八类原因中只有 292 台具备模拟单因证据，按训练 187、验证 54、测试 51 划分。源模型的推理与评估可在 CPU 完成，原根因训练程序要求 CUDA。

在同一科研环境运行 `python system/remf_app/train_risk.py` 可单独重训风险模型。脚本使用 CPU，写入 `runs/risk_时间/`，其中 `model_bundle/` 包含本次风险模型及校验文件。研究环境需另行安装；随包离线依赖供日常运行和功能复测使用。交接复测使用既有冻结权重，未重新执行 24 次 GPU 训练。
